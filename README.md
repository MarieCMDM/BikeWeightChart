# Bike Weight Chart

A Vue app for tracking bike component weight and cost, comparing alternative builds, and importing or exporting bike data as JSON. Data is saved locally in the browser.

[Live preview](https://bikeweightchart.cmdmtech.com/)

## Development

Requires Node.js 18 or newer.

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```
